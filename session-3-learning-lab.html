Stage 2 · Baseline

Learn it your usual way

The baseline topic is explicit versus recursive sequence rules. Start an 8-minute timer. Isa may take notes in her usual manner.

Tutor: Give the mini-lesson verbally. Do not coach the three-phase system yet. Isa may use the note box below or her normal notes.

Baseline mini-lesson script

A sequence is an ordered list of numbers. An explicit rule gives a direct way to calculate any term using its position. A recursive rule tells how to find a term from one or more earlier terms and must include a starting value.

Example sequence: 5, 8, 11, 14, ...

  • Explicit: aₙ = 5 + 3(n − 1)
  • Recursive: a₁ = 5 and aₙ = aₙ₋₁ + 3 for n ≥ 2

Explicit is like using a street address: go directly to the term. Recursive is like following directions from the previous location.

Isa’s baseline notes

Baseline assessment — close all notes

1. Explain the difference between an explicit rule and a recursive rule.

2. Write an explicit rule for 7, 11, 15, 19, ...

3. Write a recursive rule for 7, 11, 15, 19, ... Include the starting value.

4. Which form is usually more efficient for finding the 80th term? Explain.

5. Convert a₁ = 20, aₙ = aₙ₋₁ − 6 into an explicit rule.

Baseline self-score

Baseline answer key and scoring
  1. Explicit calculates a term directly from n; recursive calculates from previous term(s) and requires initial value(s).
  2. aₙ = 7 + 4(n − 1), equivalent aₙ = 4n + 3.
  3. a₁ = 7; aₙ = aₙ₋₁ + 4, n ≥ 2.
  4. Explicit, because it directly calculates the 80th term without generating terms 2–79.
  5. aₙ = 20 − 6(n − 1), equivalent aₙ = 26 − 6n.

Score each dimension holistically: 5 = accurate, complete, independent; 3 = mostly correct with a meaningful gap; 1 = minimal evidence; 0 = absent.

Tutor: Deliver the 10-minute lesson from facilitator mode. Isa records selective notes below. Include verbal, table, graph-description, formula, and worked-example representations.

Main lesson script: Arithmetic vs. geometric sequences

Central distinction: arithmetic sequences change by adding the same amount each step; geometric sequences change by multiplying by the same factor each step.

  1. For 4, 9, 14, 19, the consecutive differences are all +5, so d = 5.
  2. Arithmetic explicit rule: aₙ = a₁ + (n − 1)d. There are n − 1 jumps from the first term to the nth term.
  3. For 4, 12, 36, 108, each term is multiplied by 3, so r = 3.
  4. Geometric explicit rule: gₙ = g₁·rⁿ⁻¹. Again, there are n − 1 multiplications after the first term.
  5. When plotted by term number, arithmetic sequences form points on a straight line. Geometric sequences generally curve because equal steps in n create multiplicative—not additive—change.
  6. Decision rule: check differences first; if not constant, check ratios. Do not infer a pattern family from only one change.

Worked examples:

  • 6, 10, 14, 18: d = 4; aₙ = 6 + 4(n − 1); a₁₀ = 42.
  • 5, 15, 45, 135: r = 3; gₙ = 5·3ⁿ⁻¹; g₆ = 1215.

Boundary: A constant sequence can technically be arithmetic with d = 0 and geometric with r = 1, so some sequences can fit both definitions.

Stage 6 · Phase 3B

Repair the model

Feedback converts retrieval into corrected learning. Compare your reconstruction against the source and identify the precise gap.

Reference model

  • Arithmetic: constant difference d; aₙ = a₁ + (n − 1)d.
  • Geometric: constant ratio r; gₙ = g₁·rⁿ⁻¹.
  • n − 1: the first term has undergone zero changes; the nth term has undergone n − 1 changes.
  • Graph: arithmetic sequence points lie on a line; geometric sequence points usually trace a curved pattern.
  • Both: any nonzero constant sequence has d = 0 and r = 1.

Retrieval test answers

  1. Arithmetic, d = −5; aₙ = 18 − 5(n − 1).
  2. Geometric, r = 3; gₙ = 2·3ⁿ⁻¹.
  3. There are zero changes at term 1 and one fewer change than the term number.
  4. Arithmetic points align linearly; geometric points usually do not.
  5. Example: 7, 7, 7, 7, ...

Stage 7 · Transfer

Can the learning travel?

Mastery is more than repeating the example. Apply the structure when the surface details change.

Challenge 1: Two savings plans

Plan A begins at $20 and increases by $10 each week. Plan B begins at $20 and increases by 50% each week.

Challenge 2: Insufficient evidence

Two sequences both begin 3, 6. Must they follow the same pattern? Construct two valid continuations from different families and explain.

Challenge 3: Diagnose the claim

A student says, “The sequence 2, 4, 8, 16 is arithmetic because the numbers keep getting bigger by a predictable amount.” Diagnose the error and replace the claim with a reliable classification rule.

Challenge 4: Boundary case

Explain why 5, 5, 5, 5, ... can fit both sequence families. What values do d and r take?

Transfer answer key
  1. Aₙ = 20 + 10(n − 1). Bₙ = 20(1.5)ⁿ⁻¹. At week 6: A = 70; B = 151.875. Plan B eventually dominates because it compounds multiplicatively.
  2. No. Arithmetic: 3, 6, 9, 12, ... Geometric: 3, 6, 12, 24, ... Two terms establish one change but not a unique pattern family.
  3. The differences are 2, 4, 8—not constant. Ratios are all 2, so it is geometric. Reliable rule: check constant differences, then constant ratios.
  4. d = 0 and r = 1.
